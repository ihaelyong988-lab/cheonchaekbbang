## 3. 미편입 5건 (AGENTS.md §10 추가 편입 대상)

원장 62건에 대응 항목이 없고 2026-07-25 시점 코드로 결함이 성립하는 항목이다. 요지는 §1 표를 원천으로 하고 여기에는 성립 근거만 적는다. 5건의 제안 등급은 전부 '하'다.

1. **중-11** — `app.js:881-887` 수집 핸들러는 `state.questions.push` 만 수행하고 역방향 경로가 없다. 클릭 위임 선택자(`app.js:833`)에 삭제·취소 계열 `data-*` 가 0개이며, 기록 탭 문답집은 답변 textarea(`app.js:598`)만 렌더한다. 원장 8(F4)은 기록 전체 초기화와 파일 내보내기·불러오기만 포함하므로 개별 항목 철회를 대체하지 않는다.
2. **하-22** — `renderJourneyDetail`(`app.js:726-774`)에 순서 규칙·잠금 이유를 설명하는 텍스트 노드가 없다. 잠금은 `is-locked` 클래스와 `disabled` 로만 표현되고 체크박스 접근 이름은 `"${title} 읽음 체크"` 단일이다. `renderJourneyList` 의 `.notice` 는 진행 중 여정이 있을 때만 노출되어 첫 진입자에게 규칙을 전달하지 않는다. 원장 42·51 은 같은 카드의 대비·터치 타깃만 다룬다.
3. **하-23** — `renderJourneyList`(`app.js:701-724`)는 6종 전부 완료 시 모든 카드를 `disabled` + `· 완료` 로만 표시하고 전체 완주 분기가 없다. 원장에는 여정 완주 상태를 다루는 항목이 없다.
4. **하-24** — `index.html:59` `#exit-dialog`(`.exit-backdrop`)에 리스너가 없고 `app.js` 는 `#exit-stay`(`app.js:329`)·`#exit-leave`(`app.js:372`)·ESC(`app.js:332` 이후)만 처리한다. 앱 내 시트는 `data-close-overlay` 배경으로 닫히므로 관례 불일치가 유지된다. 원장 39 는 종료 팝업이 닫힐 때의 배경 inert 복원을 다루며 배경 탭 경로와 무관하다.
5. **하-26** — `manifest.webmanifest:12-16` icons 3항목 중 `purpose: "maskable"` 0건, 최상위 `id` 키 없음. 원장에는 manifest 항목이 없다.

편입 조건: 위 5건을 §10 원장에 추가할 때 등급과 게이트(기계 채점 규칙)를 함께 기입하고, 편입 완료 후 이 절의 해당 번호에 원장 번호를 병기해 미편입 상태를 해제한다.
